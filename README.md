## Projects

| Project | Question | Key result |

| [systematic-equity-research](https://github.com/vasimmer/systematic-equity-research) (description only, code private) | Does a quality tilt add value inside a Sharia-screened global equity universe? | 28-year backtest across 23 developed markets and the 1,500 largest companies a month: a quality tilt inside the screened universe raised the Sharpe ratio by about 0.20, robust to doubled costs and shifted start dates. Historical simulation gave the highest estimate, consistent with fat tails. |
